# 论文 PDF 入库

服务运行时，将 `.pdf` 文件放入配置的 `knowledge_dir`，包括子目录。后台按文件字节 hash 检测版本，保存冻结 PDF，在独立本机进程中生成 Markdown，然后进入现有逐块被动标词。没有 OCR、联网转换或转换模型调用；模型请求仍只有一个槽。

一篇 PDF 是一个来源版本，保持原文件的相对路径和 SHA-256。只有整篇转换、标词、原 PDF 当前版本和预算检查全部通过，才在一笔 SQLite 事务中发布。转换、标词等待及失败期间继续使用上一完整发布版本。新文件首次失败时没有旧版可用。删除、清空为零字节、路径非法、原文件超限或目录文件数超限仍按既有规则撤下来源；解析失败不会把部分提取文字发布，也不会给旧标注词换上新原文。零字节文件与有完整 PDF 结构但某页无法提取文字是两种情况，后一种会报需 OCR/审阅并保留旧版本。

Console 显示 PDF 排队、开始、转换完成/失败，再显示原有标词进度和完成回执。回执包括来源 ID、原 PDF digest 和仍用于回复的已发布版本；转换完成不等于已发布。`status` 显示转换限额；`observe` 的来源详情展示 Markdown、物理页序、转换警告及归档 PDF 的字节 hash 检查状态。

转换稿保存在 `state_dir/pdf_markdown/<来源版本ID去掉kb前缀>.md`。例如 `state/pdf_markdown/0123456789abcdef0123456789abcdef.md`。可以直接用编辑器查看；编辑这个文件不改变数据库中的知识版本。它不在 `knowledge/` 中，因此不会重复入库。自动导出拒绝覆盖用户改过的文件或链接；已存在且完全一致的导出可幂等恢复。不要把 `state_dir` 放在 `knowledge_dir` 内。

原 PDF 字节、转换元数据、Markdown 和标注记录保存在同一知识版本的 SQLite 状态中；这些来源版本按既有知识历史策略持续保留，不随 scratch 的滚动 24 小时删除。存储量会随 PDF 数量及编辑版本增长。转换导出也是知识审阅文件，不是 scratch 副本。仓库忽略 `state/` 与 `knowledge/`，不上传论文。

## 提取边界

使用固定 `pypdf==6.19.0`，按物理页逐页提取文字，保留提取的行序；只统一换行并去掉页面首尾空白，不猜测标题等级、段落重排、LaTeX、化学上下标、单位或表格关系。每页以 `## PDF page N` 分隔。这里的页号从 PDF 第一页算起，可能与论文印刷页码不同。

首版按可以复制文字的原生 PDF 实现。加密或损坏文件失败；任一页没有文字或少于 20 个非空白字符，整篇报告 `pdf_needs_ocr_or_review`，不会把它猜成空白页。扫描页只有页眉等少量可复制文字时仍可能漏掉图片内正文，所以提取成功不证明页面完整。公式、表格、图像、双栏顺序和乱码都需要对照 PDF 审阅；警告随版本保留。[pypdf 提取边界](https://pypdf.readthedocs.io/en/stable/user/extract-text.html)

当前没有阅读顺序推断、参考文献去重、页眉删除或图注补写。合成双栏/表格 fixture 验证了字面内容与页边界；它不证明实际论文的提取正确性、知识标签质量或科学结论。收到论文后应先对照正文、关键公式、数值/单位、表格和引用做代表性审阅，再扩大文件集。

## 独立限额

| 设置 | 默认值 | 含义 |
|---|---:|---|
| `pdf.max_file_bytes` | 16 MiB | 单个原 PDF 输入字节上限；普通文本仍为 8192 字节 |
| `pdf.max_pages` | 200 | 全篇物理页上限 |
| `pdf.max_markdown_bytes` | 512 KiB | 完整转换输出 UTF-8 上限；超限整篇失败 |
| `pdf.seconds` | 30 秒 | 每次本地转换的时间上限 |

旧配置没有 `[pdf]` 时使用上述默认值。限额在每次转换回执记录，转换不使用输入/输出模型 token。子进程超时或取消会终止并回收；进程创建、文件 I/O 和 fsync 本身仍受操作系统调度，不能承诺绝对到点完成。解析器解压内容可能大于磁盘 PDF；字节/页数/输出上限不是严格内存上限。[Python 子进程超时说明](https://docs.python.org/3/library/subprocess.html)

标词继续使用原来的 `adapter.budgets.label`、`knowledge.version_*` 累计输入/输出/时间上限和 400 字符切块配置。支持转换较长 PDF 不等于允许无限标词；过长论文或慢速模型可能触发原有版本熔断，旧版本保留，回执说明失败。没有自动增加预算、借用回复预算、裁剪剩余正文或无限重试。

相同失败 PDF digest 不自动重试；编辑原 PDF 产生新字节版本才重新排队。停机打断转换时没有模型计费，重启可从冻结 PDF 恢复，但必须原文件仍为当前版本；未知模型 usage 的中断标词保持原有不重发规则。一次失败可能留下完整的版本审阅文件，不将文件存在当成已发布证据。

## 可核验的页码与版本

转换元数据包含原 PDF hash、Markdown hash、解析器/策略版本、物理页数、每页 Markdown 字符区间和 hash、提取警告。scratch 中冻结本轮来源元数据，标出被召回文本块对应的所有物理页区间；同一文本块多处重复时保留全部位置，不冒充唯一页码。字面引用回执绑定材料版本和物理页序，仍不核验语义支持。

scratch 不存 PDF 二进制，因此单靠 scratch 的原 PDF hash 不能重算 PDF 原字节。观察页可在归档 PDF 不超过独立 16 MiB 读取限额时核对 SQLite 中的冻结字节；超过时明确显示未核验。该检查证明本地字节一致性，不证明纸面阅读顺序、公式或结论正确，也不是外部公证。
