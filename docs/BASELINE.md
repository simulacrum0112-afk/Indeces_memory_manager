# 基线与集成差异

本次是新项目，没有现存生产配置或计算科学数据迁移。下表区分保留的参考策略与为知识文档/runtime 新增的实现选择；没有修改原 Yuki。预算是工程初值，不是经过真实延迟/相关性实验调优的最优参数。

用户明确决定：使用 `hebbian-mark-graph` 策略；允许动态权重参与在线排序；聊天模型标词关闭；本地 knowledge 文件更新后触发后台被动标词。模型为 GPT-6-Luna。模型认证暂按官方 Responses API，模型请求默认串行，待进一步用户指定可调整。

参考固定版本：[8769b9ed](https://github.com/Mingyuliu-botaaa/hebbian-mark-graph/tree/8769b9ed0af3531b9fbc09fb6e084d8e7adf724d)。

| 参考原值/行为 | 本版值/行为 | 分类与影响 |
|---|---|---|
| 正 NPMI；P(A,B)=1 时为 1；4 位舍入 | 相同 | 保留核心统计公式 |
| 整篇日记文字共现 | 已完成知识文档的标注文本块共现 | 任务所需接入；粒度改变，需真实数据评估关联质量 |
| 手工标注词/缺失的 build_marks 工具 | 文件更新触发 LLM 标签，原文不改写 | 任务所需；模型语义标签尚未实测，不等于已验证事实 |
| η=1；λ=.99；6 位动态舍入 | 相同 | 保留数值 |
| 手工周期，注释建议每日 | 每次有真实直接命中的检索为一周期 | 显式工程周期；相同公式但衰减与查询频率有关 |
| shadow 动态层不参与线上；probe 未连接图扩展 | 动态边存在时取代静态边，用于一跳和排序 | 用户已明确批准的在线治理接线 |
| 先记录事件、后周期处理 | 当前直接命中事件先更新权重，再排序 | 在线实时更新扩展；未声称完全复刻原执行时序 |
| 时间戳游标 | 持久 scope/event ID 与周期表 | 纯持久性修复；防止时钟倒退与重复处理 |
| 历史不回灌为动态事件；排除自身称呼 | 相同 | 保留学习和隔离规则 |
| 一跳，每直接命中前 5 邻居，最多 2 扩展 | 相同 | 保留扩展边界；修复较弱边先去重遮蔽强边 |
| 有来源上下文时要求当前文字相交 | 相同，并要求有效 active 来源支持词对 | 保留并加强可求证来源门控；陈旧权重不能绕过归档 |
| Latin 字母两侧边界、大小写归一 | 增加数字/下划线边界 | 匹配一致性修复，避免 robot 命中 bot 等统计/查询差异 |
| IDF 与二字词评分、最低 4 分 | 直接命中数优先，再以动态/静态分数和新记录排序 | 结构化块检索适配；未保留原 IDF/min-score，相关性尚未验证 |
| 最多 3 引用、400 字格式化内容 | 最多 3 引用、预览合计≤400 字，每预览≤110 字 | 引用限制保留；完整 quote/来源另受输入 token 门禁约束 |
| 当天日记不检索 | 完成的新知识版本立即可检索 | 文档更新所需；聊天未入库，避免短期对话重复强化 |
| JSON 文件分离静态/动态 | SQLite 独立表，旧文档版本 inactive 归档 | runtime 持久性设置；不混入旧有效来源 |
| 无可靠断言的数据依赖自测 | 临时库和合成来源的 unittest | 验证公式、预算、来源和生命周期，不证明真实检索质量 |

调用和运行设置：

| 原配置 | 本版配置 | 分类 |
|---|---|---|
| 无新项目模型预算 | label 4096/512/15s；summary 16384/2048/20s；reply 16384/2048/45s | adaptor 工程预算；每行独立，不涉及科学 PES/能量参数 |
| Yuki 本地 UTF-8/framing 估算 admission | 离线估算用于水位计划，服务器计量用于生成门禁 | 任务所需 token 熔断；每阶段增加一条串行计量 HTTP 请求 |
| Yuki 100%/70% 剩余原文水位 | 相同；完整最旧前缀、每轮最多一次维护 | 上下文方法一致；不足预算明确拒绝，不隐性遗忘 |
| Yuki 大型 Console、多实例与能力路由 | 一个 Console/无头入口，一个 Gateway，一个消息队列 | 任务所需范围精简 |
| Yuki 私有/运行数据 | 无复制、无导入 | 隔离新项目；不存在科学参数或旧缓存兼容性推断 |

未来如进入科研计算，所有 XC、POTCAR、ENCUT、KPOINTS、DFT+U、频率与热力学等科学设置仍必须先提交完整原值→拟改值差异表，并按用户要求取得明确审阅批准；本项目不具备科研作业执行能力。
